# Lifely 1.15.0 — Emotional Continuity (Build 25)

Builds on 1.14.0. Reunions are playable consequences of previous, actually completed conversations rather than random replays.

## Experience
- Completing a three-round conversation saves the real partner, prior outcome, first choice, personality and age as a bounded emotional memory.
- After two or three simulated years, the other person's memory becomes ready. Talk to them through the existing People action to enter a new, three-round reunion with different choices and lines grounded in the older encounter.
- NPC reactions reflect personality and the most recent response. New chats can mention prior outcomes. The Character Story Director now references memories from previous encounters.
- Life shows ready reunions and the existing visual chronicle includes later reunions. People shows ready, scheduled, remembered and ancestral threads.
- A resolved reunion updates the actual NPC bond/trust through the existing dialogue system, writes a transcript, and may seed a later memory. Leaving the reunion does not count it as completed.
- Unavailable or deceased people leave a faded memory rather than being resurrected or forcing a punishment.

## Safety, saves and mechanics
Optional emotional state is compatible with old v2 saves. It is bounded to 24 recent threads and 8 ancestor recaps; all fields are validated. The existing per-year action is still consumed when starting any conversation, and gating is unchanged. No extra random calls, fictional guaranteed futures, payments, ads or network requests.

## Verification gate
Run: npm test; npx expo install --check; npx expo export --platform all; npm run test:e2e. New cases cover deterministic replay, age separation, old-save compatibility, expired contacts, meaningful reunion outcomes, action limits, phone widths, and save reload. Merge only when all required GitHub checks pass on the exact final code. No signed binaries or store submissions.
