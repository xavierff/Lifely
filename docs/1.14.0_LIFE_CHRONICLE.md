# Lifely 1.14.0 — Life Chronicle & Turning Points (Build 24)

This release builds on 1.13.0 without changing RNG, event selection, action costs, world state or outcomes.

## Player experience
- Life: significant resolved events become atmospheric turning-point cards with the exact choice, age, actual stat/bond/net-worth impact and scheduled future threads. Cards never block gameplay.
- Life: compact life timeline and chapter rail for Roots, Discovery, Becoming, Building and Legacy.
- More: visual chronological life history, filters for all, turning points and people, plus expandable consequence details and inherited memories.
- Generations: heirs receive a brief ancestral turning-point recap, not an old active scene.
- Older version-2 saves: the existing journal is displayed without requiring an immediate save rewrite.

## Integrity, scope and limits
The Chronicle is an observation layer. It does not roll RNG, grant awards, spend actions, generate stories or predict story outcomes. Future lines appear only when the engine has already scheduled a follow-up; scheduling never promises a successful ending. Structured history is bounded at 72 entries and ancestral recaps at 12. The existing engine journal retains its prior limits. The schema remains version 2 and supports a new optional validated chronicle object; damaged new saves use the existing backup recovery.

## QA commands
Run npm test, npx expo install --check, npx expo export --platform all, and npm run test:e2e. Coverage includes deterministic saves, exact consequences, scheduled vs unscheduled futures, older saves, bounds, inheritance, browser persistence and 320/375/430-pixel layouts.

Do not merge until both required GitHub Actions jobs are green. No signed binaries, App Store/Google Play submissions or scheduled automations were requested.
