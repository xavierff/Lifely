# Lifely 1.13.0 — Life Flow, Personalized Events & Pacing

## Purpose
The expanded life simulator needs to surface meaningful choices rather than bury players in menus. This change extends existing random event selection and provides a compact guidance board above the optional deep simulations. It never substitutes automated game outcomes for player decisions.

## Event director
The selection algorithm factors in previously played categories, exact recent event IDs, life goals, character family and career, stress, health, financial hardship, and the selected focus. It increases relevance and diversity without removing the existing mandatory annual scenario. Scenarios with two or more exclusively harmful options are less likely when the player is already under intense stress, poor health or debt. Effects for the player's actual choice remain exactly as originally authored. Existing multi-year callbacks are still honored first.

## Personalization
Family events can mention real saved relatives. Professional scenes can reference the current job, and financial scenes show current in-game cash. A past related event or travel history can appear as a contextual note without granting new abilities or fictional money. All source details stay offline in the player's own save.

## Navigation
The Life page begins with "What matters next": life stage, current focus, pressure, three immediately executable action recommendations, the last event and an optional story thread timeline. Six story focus preferences are available at no activity cost. A dedicated More section summarizes health/stress/financial pressure and story threads.

## Lifetime balance and lineage
No new currency, debt forgiveness or unapproved buffs. The probability of unavoidable harsh scenarios drops modestly for already vulnerable characters, while optional recovery/budget actions are suggested rather than executed. History arrays have explicit limits; heirs start with a fresh focus but carry limited narrative memories from prior generations.

## Acceptance tests
- npm test: optional old-save compatibility, preference change not costing actions, focus and repetition probabilities, hardship sensitivity, deterministic event records, no mutation in reads, save corruption, long-life bounds and succession.
- npx expo install --check: dependency compatibility.
- npx expo export --platform all: iOS, Android and web export.
- npm run test:e2e: visual preference change and persisted save, action suggestions, first-decision memory and 320/375/430px layouts.

## Release limits
Passing CI does not replace signed device builds, manual playtesting, screen-reader and large-type review, pacing analytics, and matched player comparison with BitLife. This version remains a development candidate. No automation was created, disabled, or changed.
