# 1.66.0 — Interactive Entertainment & Mini-Games
Build 76. Adds eight deterministic five-round arcade activities with individual scoring: football lane selection, basketball shot map, racing gear selection, musical sequence completion, cooking arithmetic, photo composition, budget-constrained production and fictional staff coordination. One activity per session, two starts per year, free gameplay, age gates, three mastery-based target scores, lifetime personal records, next-generation winning records and saved partial sessions. Uses existing engine activity budget and blocks annual progression while active. Nine engine tests and one 320px browser regression authored. This is a short turn-based puzzle arcade, not a full real-time sports or rhythm engine; career-specific medical/legal/acting sessions remain the existing decision circuits. Higher mastery raises score target (and sequence length for music), not fully dynamic opposing AI. CI and native device playtesting pending.
