# Release QA checklist
- New character: each country, background and goal; blank and maximum-length names.
- Age up: choice blocks aging and actions; resolve both choices; verify journal and stat changes.
- Work: job gates, tuition, graduation, job promotion, job loss, retirement.
- Money: insufficient funds, investments, debt repayment, real annual income/cost accounting, property and business sales.
- People: distinct bonds, gifts, marriage, breakup, children, death and heir.
- Save: background and relaunch after each type of action, pending event restore, invalid save handling, write failure recovery, rapid taps, switch between three lives, corrupt current save with valid backup, replace slot without touching other slots.
- UI: small phone, tablet, landscape, screen reader, font scaling, keyboard, Android back, safe areas.
- Release: clean dependency install, package lock, expo-doctor, Metro export, Android signed AAB, iOS signed archive, TestFlight and closed testing.
- Verify app icon, privacy declarations, age rating and rights. No real-device test has been completed yet.
