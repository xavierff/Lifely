# Lifely 1.75.0 — Release candidate (Build 85)

## Automated gates
- `npm run release:preflight`: source marketing version, native build-number consistency, original bundle/package identifiers, icon asset presence, actual catalog integrity and breadth.
- `npm test`: all existing engine regressions plus four release-candidate cases.
- CI longevity matrix: six countries for each of Balanced, Hardcore and Sandbox, up to 60 annual cycles per life (18 runs, at most 1,080 years). Saves round-trip periodically; report observed elapsed time, maximum save size and NPC count. Death may end a run earlier. A narrow scripted trajectory is not exhaustive gameplay or device performance. The audit reports unexpected blocked states rather than silently skipping them.
- Bundle export for iOS, Android and web and complete browser regressions. Source bundles are not signed binaries.

## Native candidates
EAS profiles added as an optional build route; local version source keeps Build 85 explicit. No credentials or signing secrets are stored. No automatic submission. On a configured Expo/EAS account, after CI passes, verify app ownership and signing credentials, then run:
```
npx eas-cli@latest build --profile preview --platform ios
npx eas-cli@latest build --profile preview --platform android
```
iOS internal distribution requires registered devices and Apple signing. Android preview produces an APK. Store production profile generates store-distribution builds (Android AAB). Verify existing store build numbers before running; increase the build if 85 is already used. If another native build provider is preferred, use the same version and identity. These profiles have not been executed and require actual account setup.

## Comparative playtest
Use equivalent starting circumstances where possible, ordinary-life and specialist-career sessions in each game. Recruit independent testers; counterbalance game order. Record time to first meaningful decision, comprehension, repeated choices, enjoyment (1–5), perceived agency (1–5), willingness to replay, errors and blocked actions. Include at least one long family-lineage session. Preserve anonymized observations and resolve P0 defects. Do not claim superiority over BitLife before evidence. No external competitive ranking, native build, signed binary, upload or store submission has been performed.
